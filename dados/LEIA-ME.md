# Dados

Coloque aqui as planilhas exportadas para o agente analisar:
- `dados/meta/`: Gerenciador de Anúncios do Meta (CSV)
- `dados/google-ads/`: Google Ads (CSV)
- `dados/ga4/`: Google Analytics 4 (CSV)

**Não coloque listas de clientes** (nomes, e-mails, telefones). A pasta `dados/clientes/` é ignorada pelo git justamente para isso.
