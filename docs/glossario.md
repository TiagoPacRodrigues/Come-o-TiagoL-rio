# Glossário de Marketing

Termos explicados de forma simples, com exemplos da Lírio do Vale. Vamos adicionando conforme aparecem.

| Termo | O que significa | Exemplo |
|---|---|---|
| **Funil de vendas** | O caminho da pessoa desde "nunca ouvi falar" até "comprei". Topo = descobre a marca; meio = considera; fundo = compra. | Viu um post sobre Primeira Comunhão (topo) → leu o artigo do blog (meio) → comprou o terço no site (fundo). |
| **Lead** | Pessoa que demonstrou interesse e deixou um contato (e-mail, WhatsApp). | Alguém que se cadastrou para receber novidades. |
| **Tráfego pago** | Visitas que vêm de anúncios pagos. | Anúncio no Instagram que leva para o site. |
| **Tráfego orgânico** | Visitas que vêm sem pagar anúncio (Google, redes, indicação). | Pessoa achou o blog pesquisando no Google. |
| **SEO** | Técnicas para aparecer melhor no Google sem pagar. | Escrever o artigo usando as palavras que as pessoas realmente pesquisam. |
| **Tom de voz** | O jeito da marca falar: formal ou próximo, sério ou leve. | Acolhedor e respeitoso, sem ser frio. |
| **Calendário editorial** | Planejamento do que publicar, quando e onde. | Campanha de Natal começando em outubro. |
| **CTR** | Taxa de cliques: de cada 100 pessoas que viram o anúncio, quantas clicaram. | 1.000 viram, 20 clicaram = 2% de CTR. |
| **Taxa de conversão** | De quem visitou, quantos compraram (ou fizeram a ação desejada). | 100 visitas, 2 compras = 2%. |
| **CPC** | Custo por clique: quanto se paga cada vez que alguém clica no anúncio. | Gastou R$ 50, teve 100 cliques = R$ 0,50 por clique. |
| **ROAS** | Retorno sobre o gasto em anúncios: quanto vendeu para cada real investido. | Gastou R$ 100, vendeu R$ 500 = ROAS 5. |
| **Público / segmentação** | Para quem o anúncio é mostrado (idade, região, interesses). | Mulheres 30–60, interesse em catolicismo, região Sudeste. |
| **Remarketing** | Mostrar anúncio de novo para quem já visitou o site e não comprou. | Viu a imagem de Nossa Senhora e depois vê o anúncio dela no Instagram. |
| **B2B / B2C** | B2B = empresa vendendo para empresa ou instituição. B2C = empresa vendendo para consumidor final. | Vender para uma loja ou paróquia é B2B; vender um terço para uma pessoa é B2C. |
| **Venda assistida** | Venda em que um vendedor acompanha o cliente (telefone, WhatsApp) até fechar. | Lojista chama no WhatsApp, o vendedor monta o pedido com ele. |
| **Rastreamento / atribuição** | Saber de onde veio cada cliente ou venda (qual anúncio, qual canal). | "Esse pedido de R$ 3.000 veio de um anúncio do Google." |
| **Pixel / tag** | Pedacinho de código no site que avisa a plataforma de anúncios (Meta, Google) quem visitou e o que fez. | Sem o pixel do Meta, o Instagram não sabe que um lojista visitou o site e não consegue mostrar anúncio de novo para ele. |
| **Google Tag Manager** | Ferramenta que guarda todos os pixels num lugar só, para não precisar mexer no código do site. | A equipe adiciona o pixel do Meta pelo Tag Manager, sem chamar o programador. |
| **Link interno** | Link de uma página do próprio site para outra. | Artigo do blog sobre São Bento com link para os terços de São Bento da loja. |
